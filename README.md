# CHOC - Childhood Cancer foundation Website

##What the websites is all about?
CHOC is an foundation that supports kids with cancer by providing:
- Emotional support
- Accommodations near treatment centre
- Transport to treatment
- Awareness and Advocacy
This website was built to share information about the services at CHOC and how people can help.

##Features
- Homepage with the indtroduction
- About us ,with all the information about CHOC
- Application page ,where u can apply to volunteer
- Donation page, where people can donate to help others.
- Contact us page, where u can contact the foundation if u want to take a patient there or if looking for information.
